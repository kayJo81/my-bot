# 제미나이 교차 검증

`gemini.yml` 워크플로로 제미나이 API를 부릅니다. 키는 저장소 시크릿 `GEMINI_API_KEY`에 있습니다.
답은 `scripts/cafe_cert.pem`으로 암호화해 로그에 `=====ENC-BEGIN` ~ `=====ENC-END`로 찍힙니다.
공개 저장소라 질문(prompt)과 파일 경로는 실행 정보에 보이니 민감한 내용은 넣지 않습니다.

입력
- `prompt`: 질문
- `model`: 기본 `gemini-3.8-flash,gemini-3.7-flash,gemini-flash-latest` (차례로 시도), `list`면 모델 목록
- `search`: `1`이면 구글 검색 근거 (무료 등급에서는 429로 막힘)
- `files`: 질문 뒤에 붙일 저장소 파일 (예: `blog/2026-11-18/body.txt`)

쓰는 방식 (사용자 요청, 2026-11-18)
1. 사용자가 제미나이 앱 답을 보내면: 검색으로 사실 확인 → 맞음/틀림/확인 안 됨으로 나누고 고친 답과 출처를 줍니다.
2. 질문 하나를 클로드와 제미나이에 모두: 두 답을 비교해 다른 점을 짚고 검증한 최종 답을 줍니다.
3. 블로그·시황 글을 올리기 전후에 `files`로 제미나이에게 오류를 찾게 하고, 지적은 원 출처로 다시 확인한 뒤에만 반영합니다.
제미나이 답은 그 자체로 출처가 아닙니다. 확인되지 않은 지적은 글에 반영하지 않습니다.
